# Mera Khata
Personal monthly hisaab app (PWA): Aamdani, Kharcha, Accounts (cash/bank/wallet/credit card), Transfer, Udhaar (wapsi date), Committee, Bills, Budget, Bachat goals, Har-mahine wali entries, Raseed photo, Voice entry, Search, Report (PDF/WhatsApp/CSV), Zakat, Dark mode, Notification, PIN, Backup.

## Online account (Supabase)
1. Supabase SQL Editor mein `setup.sql` chalayein.
2. Authentication > Users > Add user (client ka email + password).
3. `config.js` mein Project URL aur Publishable key likhein.
Khali config = data sirf phone mein.
